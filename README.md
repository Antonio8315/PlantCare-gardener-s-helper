# 🌿 Помічник Садовника (Gardener's Helper)

**Помічник Садовника** — це інтелектуальний Fullstack веб-додаток для визначення захворювань сільськогосподарських та декоративних рослин за сукупністю симптомів та ураженою культурою.

Сайт допомагає садівникам та городникам швидко виявити проблему (фітофтороз, борошнисту росу, сіру гниль тощо) та отримати чіткі рекомендації щодо лікування.

---

## 🛠 Стек технологій

### **Frontend**
* **React** (Vite) — швидка та реактивна побудова інтерфейсу.
* **Axios** — взаємодія з REST API бекенду.
* **CSS3 / HTML5** — адаптивний та зручний дизайн.
* **Vercel** — деплой та хостинг клієнтської частини.

### **Backend**
* **Node.js & Express.js** — побудова RESTful API та обробка запитів.
* **MongoDB Atlas & Mongoose** — хмарна NoSQL база даних та моделювання схем.
* **CORS & dotenv** — безпека, гнучке налаштування та управління змінними оточення.
* **Render.com** — хостинг та деплой API.

---

## ✨ Основні можливості

* 🔍 **Параметричний пошук:** вибір культури (томат, огірок, полуниця тощо) та множинних симптомів.
* 🧠 **Розумний алгоритм ранжування:** пошук захворювань у MongoDB за допомогою регуляторних запитів та сортування результатів від найбільшого збігу симптомів до найменшого.
* 📋 **Детальні картки хвороб:** опис патогену, візуальні ознаки та кроки для ефективного лікування/профілактики.
* 🌐 **Повна автономність у хмарі:** розгортання клієнтської та серверної частин на ізольованих сервісах (Vercel + Render + MongoDB Atlas).
